# Contributing

Thanks for taking the time to contribute.

## Reporting bugs

Please open an issue at
<https://github.com/mahmood726-cyber/hta-evidence-integrity/issues> with:

- A short description of what happened vs. what you expected.
- A minimal reproducible example (a few effect sizes / variances is usually
  enough — most of the methods only need `yi` and `vi`).
- Your `sessionInfo()`, especially the R version and `metafor` version.

## Development setup

```r
# install.packages(c("devtools", "roxygen2", "testthat"))
devtools::install_dev_deps()
devtools::document()  # regenerate man/*.Rd from roxygen comments
devtools::test()      # run the testthat suite
devtools::check()     # full R CMD check
```

The package is laid out as a standard R package:

- `R/` — one file per exported function. Roxygen comments above each
  function are the source of truth for the documentation — do not edit the
  `.Rd` files by hand. After changing the comments, run
  `devtools::document()`.
- `tests/testthat/` — unit tests. Add a new test file as
  `test-<area>.R` and aim to keep tests self-contained (the existing tests
  build a small synthetic dataset instead of relying on lazy-loaded
  `metafor::dat.bcg`).
- `man/` — generated; do not edit.
- `NAMESPACE` — generated by roxygen; do not edit by hand.

## Pull requests

Before opening a PR:

1. `devtools::document()` — keep `NAMESPACE` and `man/` in sync.
2. `devtools::test()` — all tests pass locally.
3. `devtools::check()` — 0 errors, 0 warnings, 0 notes is the goal.
4. Update `NEWS.md` under the relevant heading.
5. If you add a new exported function, add a roxygen `@export`, a test, and
   a row to the function reference table in `README.md`.

CI (`R-CMD-check`) will run `R CMD check --as-cran` on Ubuntu / macOS /
Windows × R release + oldrel-1 for every push to a PR.

## Coding style

- Follow standard R style (snake_case, two-space indentation, `<-` for
  assignment).
- Namespace-qualify every external function call (`metafor::rma`,
  `stats::qnorm`) and add a matching `@importFrom` so `NAMESPACE` stays
  precise.
- Wrap any optional dependency in `requireNamespace("pkg", quietly = TRUE)`
  and list the package under `Suggests`, not `Imports`.

## Scope

The package's scope is **robust pooling estimators for pairwise
meta-analysis**. Methods for network meta-analysis, IPD synthesis,
diagnostic test accuracy and dose–response live in companion packages.
